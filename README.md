## **Tecnologia**
Java 11 - Docker - Spring Framework - Jdbc

## **Tutorial de como rodar o projeto nord_tool_backend:**
Após clonar o projeto em sua maquina, verifique a versão do Java instalada e instale o maven para gerenciar
as dependencias do projeto.
Pelo terminar já com o mavan instalado e rodando, utilize os seguintes comandos:

mvn clean   
mvn install 

Ou instale na própria IDE o plugin do maven helper. Com isso, ele monstra todas as opções do 
maven a serem rodadas.
